# m.m (met? meet!)

업무 메신저에 붙는 다인원 회의 조율 앱. UI/UX 설계 케이스 스터디 사이트입니다.

**모두가 되는 시간이 아니라, 꼭 필요한 사람이 되는 시간**

필수 참석자와 선택 참석자를 나누고, 반복되는 개인 조건을 기억하고, 누가 아직 답하지 않았는지 보여줍니다.

## 배포

https://mary3103.github.io/mm-portfolio/

## 구성

| 항목 | 내용 |
|---|---|
| 작업 기간 | 2개월 |
| 인원 | 1인 (리서치 · UX · UI · 프로토타입) |
| 산출물 | Figma 프로토타입 23개 화면 |
| 리서치 | 직장인 6명 인터뷰, 기존 조율 서비스 분석 |

## 사이트 구조

문제 정의 → 핵심 설계 → 메신저 부가 서비스 → 사용 흐름 12단계 → 시나리오 구분 →
종료 보장 → 미팅 상태 5단계 → 디자인 시스템 → 프로젝트 정보

## 파일

```
index.html     사이트 전체 (HTML · CSS · JS 한 파일)
img/           화면 이미지 22장 (webp)
```

외부 의존성은 Pretendard 웹폰트 하나뿐입니다. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 기술

순수 HTML · CSS · JavaScript. 프레임워크와 빌드 도구를 쓰지 않았습니다.

- 반응형: Flexbox 기반, 360px부터 1920px까지 대응
- 모션: 스크롤 등장, 온보딩 애니메이션, 단계·시나리오 전환. `prefers-reduced-motion` 설정 시 모두 정지
- 폰트: Pretendard
- 색상: `#014BAA` / `#5001AA → #014BAA` / `#101010` / `#353535` / `#EBEBEB` / `#FCFCFC`
